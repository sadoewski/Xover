## Технологический стек

### Backend
- Node.js + Express
- PostgreSQL
- JWT аутентификация
- bcrypt для хеширования паролей

### Frontend
- React 19
- Vite
- Tailwind CSS
- Headless UI
- React Router
- Axios
- date-fns

## Установка и запуск

### Требования
- Node.js 18+
- PostgreSQL 14+

### 1. Установка зависимостей

```bash
npm run install:all
```

### 2. Настройка базы данных

Создайте базу данных PostgreSQL:

```bash
createdb hostprint
```

Или через psql:

```sql
CREATE DATABASE hostprint;
```

### 3. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и настройте параметры:

```bash
cd backend
cp .env.example .env
```

Отредактируйте `backend/.env` и укажите свои параметры подключения к PostgreSQL.

### 4. Миграция базы данных

```bash
cd backend
npm run db:migrate
```

### 5. Запуск приложения

Из корневой директории:

```bash
npm run dev
```

Это запустит:
- Backend API на http://localhost:5001
- Frontend на http://localhost:5173

## MVP Функционал

### ✅ Реализовано

1. **Авторизация**
   - Регистрация пользователей
   - Вход в систему
   - JWT токены
   - Защищённые маршруты

2. **Календарь**
   - Вид День (табличный с временными слотами)
   - Вид Неделя (компактный вид недели)
   - Вид Месяц (сетка месяца с задачами)
   - Отображение статистики (всего записей, выполнено, в процессе)
   - Визуальная индикация многодневных задач с ночным временем

3. **Записи (Задачи)**
   - Создание записей с полями:
     - Название
     - Описание
     - Группа
     - Вид группы (опционально)
     - Приоритет
     - Дата
     - Привязка ко времени (слоты)
   - Редактирование записей
   - Удаление записей
   - 5 статусов: Ожидается, В процессе, Выполнено, Отменен, Перенесен
   - Цветовая индикация по статусу и приоритету

4. **Группы задач**
   - Создание групп с названием, цветом и описанием
   - Создание видов групп (подкатегорий)
   - Уникальные названия

5. **Приоритеты**
   - Создание приоритетов с названием и цветом
   - Цветовая индикация в списке записей

6. **DataTask (Шаблонные задачи)**
   - Создание повторяющихся задач с расписанием
   - Назначение задач на несколько дат
   - Автоматическое отображение в календаре
   - Управление расписанием

7. **Текстовый редактор**
   - Markdown редактор для заметок
   - Создание и редактирование документов
   - Список всех документов

### 📋 Запланировано (не в MVP)

- Связи между задачами (relations)
- Дни рождения и праздники
- Админ-панель (дашборд)
- Чек-листы внутри задач

## API Endpoints

### Аутентификация
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `GET /api/auth/me` - Текущий пользователь

### Записи
- `GET /api/tasks/date/:date` - Получить записи за дату
- `GET /api/tasks/month/:year/:month` - Получить записи за месяц
- `POST /api/tasks` - Создать запись
- `PUT /api/tasks/:id` - Обновить запись
- `DELETE /api/tasks/:id` - Удалить запись

### DataTasks (Шаблонные задачи)
- `GET /api/datatasks` - Получить все шаблонные задачи
- `POST /api/datatasks` - Создать шаблонную задачу
- `GET /api/datatasks/:id` - Получить шаблонную задачу по ID
- `PUT /api/datatasks/:id` - Обновить шаблонную задачу
- `DELETE /api/datatasks/:id` - Удалить шаблонную задачу

### Группы
- `GET /api/groups` - Получить все группы
- `POST /api/groups` - Создать группу
- `GET /api/groups/:id` - Получить группу по ID
- `POST /api/groups/:groupId/types` - Создать вид группы

### Приоритеты
- `GET /api/priorities` - Получить все приоритеты
- `POST /api/priorities` - Создать приоритет
- `GET /api/priorities/:id` - Получить приоритет по ID

### Документы
- `GET /api/documents` - Получить все документы
- `POST /api/documents` - Создать документ
- `GET /api/documents/:id` - Получить документ по ID
- `PUT /api/documents/:id` - Обновить документ
- `DELETE /api/documents/:id` - Удалить документ
