## API изменения (Backend)

### Новые endpoints:
- `GET /api/rwprint/bookmarks` - получить все закладки из всех окружений

### Обновленные поля:
- `rwprint_documents.is_bookmarked` - флаг закладки (уже существовал в БД)

## Технические детали

### Компоненты:
- `RWPrintContent.jsx` - основной компонент с управлением вкладками и закладками
- `DocumentEditor.jsx` - редактор документа с кнопкой закладки
- `RWPrintContent.css` - стили для всех новых элементов

### Новые функции:
- `loadAllBookmarks()` - загрузка всех закладок
- `handleToggleBookmark(documentId)` - переключение статуса закладки
- `openDocumentInTab(doc)` - открытие документа в новой вкладке
- `closeTab(index)` - закрытие вкладки
- `deleteSelectedItems()` - удаление выбранных файлов

### CSS классы:
- `.rwprint-tabs-header` - шапка с вкладками
- `.rwprint-tab` - отдельная вкладка
- `.rwprint-tab.active` - активная вкладка
- `.rwprint-bookmarks-list` - список закладок
- `.tree-item-delete` - кнопка удаления в дереве
- `.downbar-multiselect-mode` - режим множественного выделения
