# Обновление расположения элементов управления

## Внесенные изменения

### 1. Перемещение кнопок множественного выбора в сайдбар
**Было**: Кнопки "Выбрать все" и "Удалить" находились в downbar рядом с кнопкой множественного выбора

**Стало**: Кнопки перемещены в `sidebar-footer`, отображаются внизу сайдбара когда включен режим множественного выбора

**Структура**:
```jsx
{multiSelectMode && (
  <div className="multi-select-controls">
    <button className="btn-secondary" onClick={selectAllInFolder}>
      Выбрать все
    </button>
    <button className="btn-danger" onClick={deleteSelectedItems}>
      <Trash2 size={16} />
      Удалить ({selectedItems.length})
    </button>
  </div>
)}
```

**Преимущества**:
- Кнопки находятся рядом со списком файлов
- Более логичное расположение элементов управления
- Downbar не загромождается условными элементами

---

### 2. Перемещение кнопки Split View в сайдбар
**Было**: Кнопка Split View находилась в downbar среди других кнопок

**Стало**: Кнопка перемещена в `sidebar-footer`, отображается над селектором окружения

**Структура**:
```jsx
<div className="sidebar-footer-actions">
  <button className="btn-icon-sidebar" onClick={toggleSplitView}>
    <Columns2 size={16} />
    <span>Split View</span>
  </button>
</div>
```

**Преимущества**:
- Более заметная кнопка с текстовой меткой
- Логичное расположение в нижней части сайдбара
- Всегда доступна, не зависит от режима выбора

---

### 3. Новая структура sidebar-footer
**Порядок элементов сверху вниз**:
1. Кнопки множественного выбора (когда активирован режим)
2. Кнопка Split View
3. Селектор окружения

---

## Стили

### Добавлены новые классы:
- `.multi-select-controls` - контейнер для кнопок множественного выбора
- `.btn-secondary` - стиль для кнопки "Выбрать все"
- `.btn-danger` - стиль для кнопки удаления
- `.sidebar-footer-actions` - контейнер для кнопки Split View
- `.btn-icon-sidebar` - стиль для кнопки с иконкой и текстом в сайдбаре

### Особенности стилей:
- Кнопки занимают полную ширину контейнера
- Единый отступ между элементами (12px)
- Кнопка удаления имеет красный акцент
- Disabled состояние для кнопки удаления когда ничего не выбрано
- Hover эффекты для всех интерактивных элементов
