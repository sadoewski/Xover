# Чеклист проверки синтаксиса при редактировании

## Проблема
При редактировании кода иногда возникают синтаксические ошибки из-за:
- Лишних закрывающих тегов
- Неправильного копирования/вставки
- Незакрытых скобок или тегов

## Решение: Обязательная проверка после изменений

### 1. Всегда запускать сборку после редактирования
```bash
npm run build
```
Или быстрая проверка с таймаутом:
```bash
timeout 10 npm run build 2>&1 | tail -20
```

### 2. Проверять баланс скобок/тегов при редактировании
При замене больших блоков кода убедиться что:
- ✅ Каждый `{` имеет соответствующий `}`
- ✅ Каждый `<tag>` имеет `</tag>`
- ✅ Каждый `<>` имеет `</>`
- ✅ Нет лишних закрывающих конструкций

### 3. Использовать инструменты валидации
```bash
# Проверка линтером (если настроен)
npm run lint

# Проверка TypeScript (если используется)
npm run type-check
```

### 4. Читать контекст при редактировании
Перед заменой блока кода:
1. Прочитать **до** и **после** редактируемого участка
2. Убедиться, что структура вложенности сохранена
3. Проверить отступы (indentation)

### 5. Частые ошибки при редактировании JSX

❌ **Лишний фрагмент:**
```jsx
</div>
</>  // ← лишний!
)}
```

❌ **Лишняя закрывающая скобка:**
```jsx
</div>
)}  // ← лишняя, если нет условного рендеринга
```

❌ **Несимметричные отступы:**
```jsx
<div>
  <button>
    Text
      </button>  // ← неправильный отступ
    </div>
```

✅ **Правильно:**
```jsx
<div>
  <button>
    Text
  </button>
</div>
```

## Пример из текущей ошибки

### Было (с ошибкой):
```jsx
<button onClick={() => setSortBy('oldest')}>
      {sortBy === 'oldest' && '✓ '}Сначала старые
    </button>
  </div>
</div>
</>      // ← ЛИШНИЙ!
)}       // ← ЛИШНИЙ!
```

### Стало (исправлено):
```jsx
<button onClick={() => setSortBy('oldest')}>
  {sortBy === 'oldest' && '✓ '}Сначала старые
</button>
</div>
</div>
```

## Автоматизация проверок

### Добавить pre-commit hook (опционально)
```bash
# .husky/pre-commit
npm run build
```

### Использовать IDE с подсветкой ошибок
- VS Code с расширением ESLint
- WebStorm с встроенной проверкой
- Прочие IDE с JSX поддержкой

## Быстрая диагностика

Если возникла синтаксическая ошибка:

1. **Найти строку ошибки** в сообщении компилятора
2. **Прочитать 10-20 строк до и после** проблемного места
3. **Проверить баланс** открывающих/закрывающих конструкций
4. **Посмотреть на отступы** - они часто показывают проблему
5. **Сравнить с оригиналом** (git diff)
