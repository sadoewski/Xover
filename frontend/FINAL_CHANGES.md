- **ThemeContext**: Контекст для управления темой приложения
- **ThemeProvider**: Обертка в App.jsx
- **CSS переменные**: Все цвета через переменные в theme.css
- **Переключатель**: В navbar, рядом с фото пользователя (Sun/Moon иконки)
- **Сохранение**: Выбор темы сохраняется в localStorage
- **По умолчанию**: Темная тема
