- И другие

### 4. Удален глобальный селектор `*` из theme.css

**Было**:
```css
* {
  transition: background-color 0.3s ease, color 0.3s ease, border-color 0.3s ease;
}
```

**Проблема**: Это применяло transitions ко всем элементам, что ломало анимации в Headless UI и других компонентах.

**Стало**: Удалено. Transitions применяются только там, где нужно.

### 6. Исправлена кнопка сворачивания сайдбара в RW:Print

**Было**: 
- В развернутом виде: кнопка находилась внизу footer'а
- В свернутом виде: кнопка отображалась посередине края сайдбара (абсолютное позиционирование)
- Использовались два разных компонента кнопки с разной логикой позиционирования

**Стало**:
- Создан единый контейнер `.sidebar-footer-toggle` с `margin-top: auto`
- Контейнер ВСЕГДА рендерится внизу сайдбара
- Условный рендеринг внутри контейнера:
  - Развернуто: кнопка с иконкой ChevronLeft + текст "Свернуть"
  - Свернуто: кнопка только с иконкой ChevronRight
- Удалены старые стили `.sidebar-toggle-rwprint` (абсолютное позиционирование)
- Кнопка теперь ВСЕГДА остается внизу в обоих состояниях

**Техническое решение**:
```jsx
<div className="sidebar-footer-toggle">
  {!sidebarCollapsed ? (
    <button className="sidebar-toggle-in-footer">
      <ChevronLeft /> <span>Свернуть</span>
    </button>
  ) : (
    <button className="sidebar-toggle-in-footer collapsed">
      <ChevronRight />
    </button>
  )}
</div>
```
