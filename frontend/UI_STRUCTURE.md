## Общая структура

```
┌─────────────────────────────────────────────────────────┐
│                        NAVBAR                           │
└─────────────────────────────────────────────────────────┘
┌─────────────────┬───────────────────────────────────────┐

└─────────────────┴───────────────────────────────────────┘
│                       DOWNBAR                           │
└─────────────────────────────────────────────────────────┘
```

## Компоненты по зонам

### SIDEBAR (левая панель)

#### Верхняя часть - Вкладки
- **Файлы** - список документов и папок текущего окружения
- **Сайты** - список доступных сайтов
- **Закладки** - избранные документы из всех окружений

#### Средняя часть - Контент
- Дерево папок с возможностью раскрытия/сворачивания
- Список документов
- Чекбоксы для множественного выбора (когда режим активен)

#### Нижняя часть - Footer (снизу вверх)
1. **Селектор окружения** (всегда)
   - Текущее окружение
   - Dropdown для переключения/создания

2. **Кнопка Split View** (всегда)
   - Включение/выключение разделенного вида
   - Полноразмерная кнопка с иконкой и текстом

3. **Кнопки множественного выбора** (условно)
   - Появляются только когда активирован режим выбора
   - "Выбрать все"
   - "Удалить (N)" с счетчиком

---

### MAIN CONTENT (центральная область)

#### Горизонтальные вкладки документов
- Отображаются когда открыт хотя бы один документ
- Показывают название документа
- Кнопка закрытия (×) на каждой вкладке
- Переключение между открытыми документами

#### Область редактора
- **Обычный режим**: один редактор на всю ширину
- **Split View**: два редактора рядом (левый и правый)
- Каждый редактор содержит:
  - Toolbar (жирный, курсив, списки и т.д.)
  - ProseMirror editor для редактирования
  - Кнопка включения подсветки синтаксиса

---

### DOWNBAR (нижняя панель)

#### Левая часть
- Информация о текущем документе
- Статистика (слова, символы)

#### Правая часть
- **[✓]** - Включение режима множественного выбора
- **[+Док]** - Создать новый документ
- **[+Папка]** - Создать новую папку
- **[⚙️]** - Настройки
- **[⇅]** - Сортировка (alphabetical, newest, oldest)

## Состояния и режимы

### Режим множественного выбора
**Активация**: Клик на кнопку [✓] в downbar

**Что изменяется**:
- ✅ Появляются чекбоксы у каждого элемента в списке
- ✅ В sidebar-footer появляются кнопки "Выбрать все" и "Удалить"
- ✅ Пропадают иконки удаления у отдельных элементов
- ✅ Кнопка [✓] в downbar подсвечивается как активная

### Split View режим
**Активация**: Клик на кнопку "Split View" в sidebar-footer

**Что изменяется**:
- ✅ Область редактора делится на две части
- ✅ Можно открыть два документа одновременно
- ✅ Каждая часть имеет независимую панель инструментов
- ✅ Кнопка "Split View" подсвечивается как активная
- ✅ Resize handler между панелями для изменения ширины

## Сохранение состояния (localStorage)

При перезагрузке страницы восстанавливается:
- ✅ Открытые документы и выбранная вкладка
- ✅ Текущее окружение и папка
- ✅ Раскрытые папки в дереве
- ✅ Split View состояние и размеры панелей
- ✅ Состояние подсветки синтаксиса для каждого документа
- ✅ Все настройки интерфейса

## CSS переменные и темизация

Используются CSS-переменные для цветов:
- `--bg-primary` - основной фон
- `--bg-secondary` - вторичный фон (sidebar)
- `--bg-tertiary` - третичный фон (кнопки)
- `--bg-hover` - фон при наведении
- `--text-primary` - основной текст
- `--text-secondary` - вторичный текст
- `--accent-primary` - акцентный цвет
- `--border-primary` - цвет границ

## Ключевые особенности

### Подсветка синтаксиса
- Использует ProseMirror декорации
- Анализирует морфологию через API
- Сохраняет состояние для каждого документа
- Цветовое кодирование по частям речи

### Множественные вкладки
- Неограниченное количество открытых документов
- Каждая вкладка независима
- Состояние редактора сохраняется при переключении
- Можно закрыть любую вкладку

### Split View
- Изменяемая ширина панелей (drag & resize)
- Независимые редакторы
- Можно открыть разные документы
- Состояние сохраняется в localStorage

### Закладки
- Работают между окружениями
- Документ из любого окружения можно добавить в избранное
- При переключении закладки документы не пропадают
