# Быстрая инструкция по синхронизации базы данных на сервере

## Проблема решена! ✅

Создана полная система миграций для синхронизации базы данных между локальной и продакшн версией.

## Что делать на сервере:

### 1. Сделай бэкап (ОБЯЗАТЕЛЬНО!)

```bash
# Подключись к серверу
ssh your-server

# Перейди в папку с приложением
cd /path/to/hostprint/backend

# Создай бэкап базы данных
pg_dump -U your_db_user -d your_db_name > backup_$(date +%Y%m%d).sql
```

### 2. Запусти миграции

```bash
npm run db:migrate:all
```

### 3. Перезапусти приложение

```bash
# PM2
pm2 restart backend

# Или Docker
docker-compose restart backend
```

### 4. Проверь логи

```bash
pm2 logs backend
# или
docker logs -f hostprint-backend-1
```
