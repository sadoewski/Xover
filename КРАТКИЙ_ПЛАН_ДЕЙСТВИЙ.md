## 🚨 ТОП-3 ГЛАВНЫЕ ПРОБЛЕМЫ

### 1. Пользователь не видит ошибки ❌
- 90+ ошибок только в console.log
- Юзер видит зависший UI и не понимает что случилось
- **Это убивает доверие к приложению**

### 2. Производительность Groups 💣
- 372 последовательных API запроса
- Страница грузится 30+ секунд
- **Страница непригодна для использования**

### 3. Скрытые баги 🐛
- JSON.parse без try-catch → крашнут весь app
- Race conditions в auth и календаре
- Утечки ресурсов в Python subprocess
- **Вылезут в самый неожиданный момент**
