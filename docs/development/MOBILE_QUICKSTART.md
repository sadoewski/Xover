## Как открыть на телефоне

### Вариант 1: Через локальную сеть (для разработки)
1. Запустите backend и frontend на компьютере
2. Узнайте IP адрес компьютера:
   - macOS/Linux: `ifconfig | grep "inet "` 
   - Windows: `ipconfig`
3. На телефоне откройте браузер и введите: `http://[IP-адрес]:5173`
   - Например: `http://192.168.1.100:5173`

### Вариант 2: Через удаленный сервер (продакшн)
1. Разверните приложение на сервере с доменом
2. Откройте домен в браузере телефона
3. Готово!

### Вариант 3: Docker (рекомендуется)
1. Запустите через Docker:
   ```bash
   docker-compose up
   ```
2. Откройте на телефоне: `http://[IP-сервера]:3000`

## Особенности для iOS

### Safari на iPhone
- При первом открытии может появиться запрос на разрешение
- Рекомендуется добавить на домашний экран для быстрого доступа
- Работает как почти нативное приложение

### Добавление на домашний экран (PWA режим)
1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться" 
3. Выберите "На экран Домой"
4. Готово! Теперь можно открывать как приложение

## Особенности для Android

### Chrome на Android
- Работает нативно без дополнительных настроек
- Можно установить как PWA (появится предложение)

## Рекомендации

### Для лучшего опыта:
- Используйте последние версии браузеров
- Включите JavaScript
- Разрешите cookies
- Для iOS используйте Safari (другие браузеры могут работать медленнее)
- Для Android используйте Chrome

### Сетевые требования:
- Стабильное Wi-Fi или 4G/5G соединение
- Низкий ping для плавной работы
- Доступ к серверу (проверьте firewall)

## Известные проблемы

### iOS Safari
- Может быть небольшая задержка при первом открытии
- Видео могут требовать взаимодействия пользователя для автовоспроизведения

### Android Chrome
- На некоторых устройствах анимации могут быть медленнее
- Samsung Internet может иметь небольшие отличия в отображении

## Troubleshooting

### Не открывается на телефоне
1. Проверьте что телефон и компьютер в одной сети
2. Проверьте firewall на компьютере
3. Попробуйте перезапустить dev server
4. Убедитесь что используете правильный IP адрес

### Интерфейс не адаптируется
1. Очистите кэш браузера
2. Перезагрузите страницу (Ctrl+R)
3. Проверьте что используете современный браузер

### Формы зумятся на iOS
1. Это исправлено в коде (font-size: 16px)
2. Если проблема осталась - обновите браузер
3. Попробуйте добавить сайт на домашний экран

### Медленно работает
1. Проверьте скорость интернета
2. Закройте другие вкладки
3. Перезапустите браузер
4. Проверьте нагрузку на сервер

## Поддержка

Если нашли проблему:
1. Проверьте консоль браузера (F12 на десктопе)
2. Сделайте скриншот
3. Опишите модель устройства и версию браузера
4. Создайте issue в репозитории
