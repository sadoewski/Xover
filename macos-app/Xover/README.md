# Xover - Hostprint macOS App

Native macOS application for Hostprint using SwiftUI and embedded Node.js backend.

## Architecture

### Components

1. **XoverApp.swift** - Main app entry point with SwiftUI lifecycle
   - App-level state management
   - Window and settings scene configuration
   - Server status tracking

2. **AppDelegate.swift** - Application lifecycle and backend management
   - Launches embedded Node.js backend on startup
   - Monitors backend health
   - Manages backend process lifecycle
   - Environment variable configuration

3. **ContentView.swift** - Main window with WKWebView
   - Embeds web UI from backend server
   - Status bar with server status and navigation controls
   - Loading states and error handling
   - Backend connection monitoring

4. **WebViewBridge.swift** - Swift <-> JavaScript communication
   - Message passing between native and web layers
   - Native feature exposure (notifications, file dialogs, clipboard)
   - System information access
   - Custom event dispatching

5. **MenuCommands.swift** - Native macOS menu bar
   - File operations (new task, new data task)
   - View controls (zoom, reload, dev tools)
   - Backend management (start, stop, restart)
   - Navigation shortcuts (⌘1-5 for main sections)

6. **PreferencesView.swift** - Settings window
   - Backend configuration (port, auto-start)
   - Database settings
   - Developer options
   - Cache management

## Backend Integration

The app embeds the Node.js backend and manages it automatically:

1. **Startup**: Backend launches on app start (if auto-start enabled)
2. **Port**: Default 5000, configurable in Preferences
3. **Health**: Monitors backend via `/api/health` endpoint every 5s
4. **Shutdown**: Backend terminates gracefully on app quit

### Environment Variables

The app configures the backend with:
```bash
PORT=5000
NODE_ENV=production
DB_HOST=localhost
DB_PORT=5432
DB_NAME=hostprint
JWT_SECRET=<auto-generated>
ALLOWED_ORIGINS=http://localhost:5000
```

Additional settings loaded from embedded `.env` file if present.

## Swift <-> JavaScript Bridge

The bridge enables native features from web code:

```javascript
// Log to native console
window.swift.log('Message from JS');

// Show native notification
window.swift.showNotification('Title', 'Body text');

// Open URL in default browser
window.swift.openExternal('https://example.com');

// Get system info
window.swift.getSystemInfo((info) => {
  console.log(info.platform, info.version);
});

// Copy to clipboard
window.swift.copyToClipboard('Text to copy');

// File selection dialog
window.swift.selectFile(['txt', 'md'], (result) => {
  if (result) {
    console.log('Selected:', result.path);
  }
});

// Save file dialog
window.swift.saveFile('export.json', jsonData, (result) => {
  console.log('Saved:', result.success);
});
```

## Development

### Running in Xcode

1. Open `Xover.xcodeproj` in Xcode
2. Select target scheme
3. Run (⌘R) or build (⌘B)
4. App launches with backend auto-start

### Building for Distribution

1. Archive the app (Product → Archive)
2. Export for distribution
3. Code sign with Developer ID
4. Notarize with Apple
5. Create DMG installer

### Embedding Backend

For release builds, embed the backend:

```bash
# Build backend
cd ../../backend
npm ci --production
npm run build  # if build step exists

# Copy to Xcode Resources
cp -r . ../macos-app/Xover/Resources/backend/
```

Update Xcode build phases to include backend in bundle.

## Sandboxing

The app uses macOS App Sandbox with these entitlements:

- **Network Client/Server** - Backend HTTP server
- **User Selected Files** - File upload/download
- **JIT** - Node.js V8 engine
- **Unsigned Executable Memory** - Node.js runtime
- **Library Validation** - Native modules

## Troubleshooting

### Backend won't start
- Check Preferences → Backend → Port (ensure not in use)
- Verify Node.js installed: `/usr/bin/env node --version`
- Check Console.app for crash logs

### WebView shows error
- Ensure backend is running (green status)
- Check port matches in Preferences
- Try Backend → Restart Backend

### Can't connect to database
- Verify PostgreSQL running on localhost:5432
- Check database credentials in backend `.env`
- Run migrations: `cd backend && npm run db:migrate`

### Bridge not working
- Check Web Inspector console for errors
- Verify `window.swiftBridgeReady` is true
- Reload WebView (⌘R)

## Distribution

### Signing

```bash
codesign --deep --force --verify --verbose \
  --sign "Developer ID Application: Your Name (TEAM_ID)" \
  Xover.app
```

### Notarization

```bash
xcrun notarytool submit Xover.app \
  --apple-id "your@email.com" \
  --team-id "TEAM_ID" \
  --password "app-specific-password"
```

### DMG Creation

```bash
create-dmg \
  --volname "Hostprint" \
  --window-pos 200 120 \
  --window-size 800 400 \
  --icon-size 100 \
  --app-drop-link 600 185 \
  "Hostprint-1.0.0.dmg" \
  "Xover.app"
```
