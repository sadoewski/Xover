# Руководство по тестированию упрощенного интерфейса

## Запуск приложения

### Development режим
```bash
cd /Users/sadoewski/projects/Xover/frontend
npm run dev
```
Откройте http://localhost:5173 в браузере

### Production сборка
```bash
cd /Users/sadoewski/projects/Xover/frontend
npm run build
```

## Что тестировать

### 1. Desktop (> 1024px)

#### Сайдбар
- [ ] Сайдбар отображается слева
- [ ] Логотип "Xover" виден в header сайдбара
- [ ] Кнопка сворачивания работает корректно
- [ ] Resize handle (изменение ширины) работает
- [ ] В футере сайдбара есть:
  - [ ] Кнопка "Настройки"
  - [ ] Переключатель темы (Светлая/Темная)
  - [ ] Профиль пользователя
  - [ ] Кнопка выхода

#### Навигация
- [ ] Админ-панель (/)
- [ ] Раздел XOVER раскрывается/сворачивается
  - [ ] Календарь
  - [ ] События
  - [ ] DataTask
  - [ ] Группы
  - [ ] Приоритеты
  - [ ] Shell
- [ ] Активная страница подсвечивается
- [ ] При клике происходит переход

#### Breadcrumbs
- [ ] Breadcrumbs отображаются внизу страницы
- [ ] Показывают текущий путь навигации
- [ ] Клик по элементу breadcrumb работает
- [ ] Последний элемент неактивен

#### Настройки
- [ ] Переход в настройки работает (через сайдбар)
- [ ] Две вкладки: "Внешний вид" и "Пользователи"
- [ ] Вкладка "Файлы" отсутствует
- [ ] В UsersSettings нет статистики RWPrint

#### Переключатель темы
- [ ] Клик переключает тему
- [ ] Иконка меняется (Солнце/Луна)
- [ ] Тема сохраняется в localStorage

### 2. Tablet (768px - 1024px)
- [ ] Сайдбар уже (200px по умолчанию)
- [ ] Все функции работают как на desktop
- [ ] Breadcrumbs адаптированы (меньший шрифт)

### 3. Mobile (≤ 767px)

#### Сайдбар как выдвижное меню
- [ ] Сайдбар скрыт по умолчанию
- [ ] Кнопка меню-гамбургер видна в левом верхнем углу
- [ ] Клик открывает меню слева
- [ ] Появляется полупрозрачный overlay
- [ ] Клик по overlay закрывает меню
- [ ] Клик по пункту меню закрывает меню и переходит на страницу

#### Адаптация контента
- [ ] Breadcrumbs уменьшены (10px шрифт)
- [ ] Breadcrumbs прокручиваются горизонтально
- [ ] Resize handle не работает (отключен)
- [ ] Весь контент помещается на экране

#### Footer сайдбара на мобильных
- [ ] Кнопки "Настройки" и "Тема" видны
- [ ] Профиль пользователя корректно отображается
- [ ] Все элементы кликабельны

### 4. Функциональность

#### Все страницы доступны:
- [ ] Админ-панель (Dashboard)
- [ ] Календарь
- [ ] События
- [ ] DataTask
- [ ] Группы записей
- [ ] Приоритеты
- [ ] Шаблоны задач
- [ ] Shell/Terminal
- [ ] Настройки

#### Страницы НЕ доступны (удалены):
- [ ] RWPrint (должна перенаправлять или 404)
- [ ] Sites/:id (должна перенаправлять или 404)

### 5. Темы

#### Светлая тема
- [ ] Фон светлый
- [ ] Текст темный
- [ ] Сайдбар светлый
- [ ] Breadcrumbs читаемы

#### Темная тема
- [ ] Фон темный
- [ ] Текст светлый
- [ ] Сайдбар темный
- [ ] Breadcrumbs читаемы

### 6. Переходы и анимации
- [ ] Сворачивание сайдбара плавное
- [ ] Открытие мобильного меню плавное
- [ ] Hover эффекты работают
- [ ] Активные состояния видны

## Известные проблемы для проверки
1. После удаления RWPrint убедитесь, что нет битых ссылок
2. Проверьте что модальные окна открываются поверх контента
3. Убедитесь что логаут корректно очищает состояние

## Инструменты для тестирования

### Chrome DevTools
```
F12 -> Toggle Device Toolbar (Ctrl+Shift+M)
```
Тестируйте разные размеры:
- iPhone SE (375x667)
- iPhone 12 Pro (390x844)
- iPad (768x1024)
- iPad Pro (1024x1366)

### Responsive Design Mode
В DevTools выберите:
- Mobile: 375px
- Tablet: 768px
- Desktop: 1440px
